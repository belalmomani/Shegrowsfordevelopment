# She Grows for Development — نظام إدارة البرامج وقياس الأثر

نظام منخفض التكلفة لإدارة البرامج والطلبات والأعضاء والحضور وقياس الأثر، بلوحة إدارة على المتصفح وتطبيق PWA/أندرويد للمستفيدات.

**الحالة:** المرحلة 1 مكتملة (تصميم وتوثيق). لا يوجد كود تشغيلي بعد.

## المحتويات
| المسار | الوصف |
|---|---|
| `docs/01-site-findings.md` | نتائج فحص الموقع وما لم يُفحص |
| `docs/02-architecture.md` | التقنية والاستضافة والأمن وبنية الملفات |
| `docs/03-sitemap-and-roles.md` | الصفحات والأدوار والصلاحيات |
| `docs/04-phase-plan.md` | المراحل وشروط القبول والأسئلة المفتوحة |
| `database/schema.sql` | مخطط قاعدة البيانات (42 جدولا) + بيانات مرجعية |
| `backend/config/config.example.php` | قالب الإعدادات |

## قبل الرفع إلى GitHub
1. اجعل المستودع **Private**.
2. لا ترفع `config.php` ولا أي كلمات مرور أو مفاتيح (مستثناة في `.gitignore`).
3. لا تضع بيانات مستفيدات حقيقية في المستودع أبدا.

## ملاحظة
مخطط قاعدة البيانات خضع لفحص ساكن (أسماء الجداول والمفاتيح الأجنبية وتطابق الأنواع) ولم يُشغَّل على MySQL فعليا بعد. تشغيله وفحصه على قاعدة اختبار أول خطوة في المرحلة 2.
